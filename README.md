# Face / Signal

一个全屏、手势驱动的表情研究。通过 MediaPipe Hands 读取手掌张开程度，连续控制 50 帧表情画面：**捏合 → 严肃，张开 → 微笑**。

## 运行（macOS 桌面端）

摄像头 API 需要安全上下文，请通过本地服务器访问，不要直接双击打开 `index.html`。

最简单的方式是双击 **`start.command`**。它会启动本地服务器并打开浏览器。

也可以手动启动：

```bash
cd "/Users/charlotte/Desktop/ai music code/gesture-face"
python3 -m http.server 4173 --bind 127.0.0.1
```

然后打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。

- 首次进入点击「开启手势体验」，允许浏览器使用摄像头。
- 捏合手指 / 握拳：表情逐渐严肃。
- 张开手掌：表情逐渐微笑。
- 摄像头不可用时，可使用「先用鼠标体验」，左右移动指针控制同一套动画。
- 若浏览器没有弹出摄像头授权，请检查地址栏权限，并确认没有其他程序独占摄像头。
- 如果页面提示摄像头已连接但迟迟没有画面，通常是因为当前浏览器的内置/预览环境限制了视频采集。请改用 **Chrome 或 Safari** 打开上面的地址。
- 如果小窗显示 `TRACKER ERROR` 或 `MediaPipe: ... activeTexture`，说明当前浏览器无法创建 WebGL 上下文。MediaPipe 即使使用 CPU 推理，也需要 WebGL 来上传图像。请开启 Chrome 的「使用图形加速」并重启，或改用 Safari / Firefox。
- 如果小窗里能看到手、但状态仍是「未识别到手」，请先**张开手掌**把整只手（包括手腕）放进右侧取景框，手掌面向镜头，距离约一臂，并保持光线充足；锁定后再捏合。
- `?demo=1` 可直接进入鼠标演示模式。

## 实现

- `assets/frames/`：提供的录像中全部 50 帧，经过逐帧人脸对齐、统一裁切并移除界面干扰后，以 WebP 编码。为了让「张开→微笑、捏合→严肃」的方向保持一致，50 帧全部保留并按表情变化重新编排；原片前段较平静的镜头被放在低微笑强度的位置。
- `app.js`：手势张开度测量、One Euro 平滑、逐帧插值与 UI 状态。
- `assets/mediapipe/`：本地 MediaPipe Tasks Vision、WASM 运行时和 Hand Landmarker 模型；所有画面处理都在浏览器本地完成。
- 无构建步骤，纯静态 HTML / CSS / JavaScript；除页面自身资源外不发任何网络请求。

## 手势映射

手部张开度由三项信号融合得到：四指伸直程度、指尖相对掌心的展开方向、拇指与食指的捏合距离。结果经过 One Euro 平滑后连续控制 50 帧画面，不使用播放/暂停逻辑。握拳或捏合会走到 0%（严肃），张开手掌会走到 100%（微笑），中间值会实时混合相邻两帧。


## 全息粒子散开体验

新增了一个独立的实时 3D 体验：[打开 HOLO / DISPERSION](http://127.0.0.1:4173/holo/)。

- 张开手指：人物在立方体中散成彩色粒子。
- 合拢手指：粒子回收，人像重新凝聚。
- 线框、轮廓扫描光和地面投影使用冷蓝色；人像本身保留自然色。
- 支持手势、自动演示和鼠标控制。需要 WebGL；若当前浏览器不可用，请使用 Safari 或开启硬件加速。
