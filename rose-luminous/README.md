## 说明

GLB 是完整的酒红玫瑰 PBR 模型；实时页面的金色微尘、柔光轮廓和 Bloom 是浏览器中的效果层。两者的花束形态完全一致，可直接把 GLB 放进白色线框立方体里做缓慢旋转。

叶片与花茎通过叶柄连接；所有叶片都依附于花茎，没有零散悬浮叶片。花茎在底部自然并拢，没有额外的绑带或丝带。
